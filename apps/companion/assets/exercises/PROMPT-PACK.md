# Exercise visuals — AI image/video prompt pack

Generate an **owned, consistent, female** figure set in a clean WorkoutLabs-style look, then drop each into `photos/` (see PHOTO-GUIDE.md) and the app shows it. Use any image generator (Midjourney, DALL·E / ChatGPT, Ideogram, Leonardo).

## 1 · Locked STYLE block — paste this before EVERY movement line
```
Clean flat vector illustration of the same mid-30s woman demonstrating an exercise, full body in frame, simple instructional fitness-app style, smooth rounded shapes, minimal flat shading, calm muted palette (teal #1f8a7f and slate-blue #1f6a92 activewear, warm neutral skin, hair in a low ponytail), plain off-white background, soft ground shadow, even lighting, centred, modest athletic wear, no text, no logos, consistent character and style across all images —
```

## 2 · Negative prompt (tools that take one)
```
photorealistic, text, watermark, logo, extra people, distorted anatomy, extra limbs, sexualised, revealing clothing, cluttered background, harsh shadows
```

## 3 · Keeping all 30 consistent (the hard part)
- Generate **one** figure first (a simple standing pose). Keep it as your reference.
- **Midjourney:** add `--cref <url-of-your-reference> --cw 80 --ar 4:5 --style raw` to every prompt (character reference locks the same woman). `--sref` locks the style.
- **DALL·E / ChatGPT:** attach your reference image and say “same woman, same style as the reference” each time.
- **Ideogram / Leonardo:** use their character/style-reference feature; keep the STYLE block identical and the same aspect ratio (4:5).
- Keep **view** as written (most are side profile) so the set reads uniformly.

## 4 · Video (optional, later)
Take each finished still and use an **image-to-video** tool (Runway Gen-3, Kling, Pika) with a short motion prompt, e.g. “the woman performs one slow, controlled rep of this movement and returns to the start, smooth loop, fixed camera, same style.” Export a short MP4/GIF and drop it in `photos/` with the same filename (`.mp4`/`.gif`).
