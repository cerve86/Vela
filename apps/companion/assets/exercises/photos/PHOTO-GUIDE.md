# Photographing your exercise demos

One clean static photo per movement. Follow this and the set will look consistent and on-brand.

## How to shoot (5-minute setup)

- **Background:** one plain, light wall or a tidy clinic/studio corner — the *same* spot every time, so the set matches.
- **Light:** face a window or soft daylight; no harsh overhead shadows, no backlight.
- **Framing:** phone **portrait**, whole body with a little headroom, camera at **hip height**, level and square (not angled).
- **Wear:** fitted leggings/shorts + fitted top so hips, knees and ankles read; plain colours.
- **The moment:** shoot the **position that defines the movement** — the hold, or the loaded end of the rep (top of the calf raise, bottom of the split squat, the Pallof pressed out).
- **Model:** you or a willing client/Run&Bun member. One person across the set keeps it cohesive.
- **Keep it warm and human** — relaxed face, good posture. This is your brand, not a gym catalogue.

## Saving them

Save each as a **.jpg** with the exact filename below, into this `photos/` folder. The app picks it up automatically — no code change. Add them in any order; each slot fills as you go.
